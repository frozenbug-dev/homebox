# Homecrate

The Homebox mobile app, built with [Expo](https://expo.dev) (SDK 58) and Expo Router.

## Stack

| Concern       | Library                                                                                       |
| ------------- | --------------------------------------------------------------------------------------------- |
| Routing       | `expo-router` (native tabs, routes in `src/app/`)                                             |
| Dev builds    | `expo-dev-client`                                                                             |
| Styling       | `react-native-unistyles` v3 — themes in `src/theme/unistyles.ts`                               |
| Native UI     | `@expo/ui` (SwiftUI / Jetpack Compose), `expo-glass-effect`, `expo-haptics`                  |
| Animation     | `react-native-reanimated` v4 + `react-native-worklets`                                        |
| Gestures      | `react-native-gesture-handler` v3 (swipeable rows)                                            |
| Keyboard      | `react-native-keyboard-controller` (`KeyboardProvider` in the root layout)                     |
| Data fetching | `@tanstack/react-query`, `@tanstack/react-form`                                               |
| Networking    | `react-native-nitro-fetch` — replaces global `fetch`/`XMLHttpRequest` in `src/lib/polyfills.ts` |
| Camera        | `react-native-vision-camera` v5 (+ `react-native-nitro-image`)                                |
| Lists         | `@shopify/flash-list` v2                                                                      |

See [`AGENTS.md`](./AGENTS.md) for design and library guidance (native-first UI, Liquid Glass / Material 3, interactions).

## Development

Unistyles, VisionCamera and Nitro Fetch ship native code, so **Expo Go is not supported** — use a development build.

```bash
pnpm install
pnpm ios       # expo run:ios — builds the dev client and launches the simulator
pnpm android   # expo run:android
pnpm start     # Metro in dev-client mode (expo start --dev-client), once a dev build is installed
```

From the repo root: `task mobile:dev`, `task mobile:ios`, `task mobile:android`, `task mobile:check` (or `mise run mobile`).

`ios/` and `android/` are generated by `expo prebuild` (Continuous Native Generation) and are not committed — configure native behaviour in `app.json`.

## Signing in

The first screen asks for the Homebox server address, then offers whatever that
server allows (`GET /api/v1/status`): email + password and/or OIDC.

- **Password**: `POST /users/login`; the bearer token is kept in `expo-secure-store`
  and refreshed (`/users/refresh`) when less than three days are left.
- **OIDC**: the app opens `/users/login/oidc?redirect_uri=homecrate://auth/callback&code_challenge=…`
  in the system browser (`expo-web-browser`). The server redirects back with a
  single-use code, which the app exchanges together with its PKCE verifier at
  `POST /users/login/oidc/exchange`. Needs a server with this change; the
  redirect URI must be in `HBOX_OIDC_APP_REDIRECT_URIS` (the default includes it).

Requests never send cookies (`credentials: 'omit'`): the server prefers its
session cookie over the `Authorization` header.

### Testing locally on Android

```bash
docker compose -f docker-compose.dev.yml --profile oidc up -d   # postgres, mailpit, mock OIDC on :8080
HBOX_OIDC_ENABLED=true HBOX_OIDC_ISSUER_URL=http://localhost:8080/default \
  HBOX_OIDC_CLIENT_ID=homebox HBOX_OIDC_CLIENT_SECRET=secret task go:run:postgresql
adb reverse tcp:7745 tcp:7745 && adb reverse tcp:8080 tcp:8080
```

Then use `localhost:7745` as the server. Demo mode signs in as
`demo@example.com` / `demodemo`; the mock OIDC page accepts any user, with claims
such as `{"email": "oidc@example.com", "name": "OIDC User"}`.
